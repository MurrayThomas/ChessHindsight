Engine

        

        

          
          
          
          
          
        

        

          More lines means more search for the same depth, so raising this makes
          each evaluation slower. Three is the usual balance.
        

        

          Depth is the same setting as the dropdown under every board, so change
          it wherever you happen to be. Each extra ply costs roughly 60% more
          time — 25 is seconds to a minute per position where 18 is about one
          second. No search runs longer than two minutes; if the clock stops one
          early, the board says so and reports the depth it did reach.
        

        

          Threads and hash are separate settings, not a ratio. Threads is how
          many cores search; half your physical cores is usually the whole gain,
          and counting the hyperthreads is not — searching several lines at once
          parallelises poorly, so expect about a third off the time, not a
          quarter of it. Hash is how much of the tree the engine remembers, and
          it is kept between positions, so walking a line reuses it: 512–1024 MB
          is worth roughly another tenth, and more than that buys nothing at
          these search lengths. Neither is a substitute for the depth you pick.
        

        
      


      

        
Indexing

        

          Positions are indexed up to this many plies for the explorer and the
          positions view. Raising it makes deeper lines searchable; full move
          lists are always stored, so changing this only needs a reindex, never
          a re-download.
        

        

          
          
          
          
        

      


      

        
Lichess API token (optional)

        

          Raises the Lichess export rate limit. Only needed if syncing a large
          account feels slow. Create one at lichess.org › Preferences › API access tokens;
          no scopes are required for public game export.
