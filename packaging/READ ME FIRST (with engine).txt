ChessHindsight
==============

A desktop app for analysing your own chess games in bulk, from Chess.com,
Lichess and PGN files.

Everything you need is in this folder. There is nothing else to download.


RUNNING IT
----------

Unzip this folder anywhere you like - Desktop, Documents, a USB stick. It does
not matter where, and there is no installer. Then double-click:

    ChessHindsight.exe

Keep the folder together. The exe, the "stockfish" folder and the "data" folder
that appears on first run all belong side by side. If you want to move the app
later, move the whole folder and your history comes with it.

Two things will probably happen the first time you run it, and neither means
anything is broken:

  * Windows SmartScreen shows a blue "Windows protected your PC" box. That is
    because the app is not code-signed - a certificate costs a few hundred
    pounds a year and this is a personal project. Click "More info", then
    "Run anyway". You will only see it once.

  * Your antivirus may flag it. Apps built this way - Python packed into a
    single .exe - trip heuristic detection fairly often. It is a false positive.


GETTING YOUR GAMES IN
---------------------

Open Settings inside the app and add your Chess.com and/or Lichess username,
then run a sync. The first sync downloads your whole history and can take a
while - it is fetching every game you have ever played. Later syncs only pick up
what is new, and are quick.


THE ENGINE
----------

Stockfish is already included, in the "stockfish" folder, and the app finds it
automatically. You do not need to configure anything.

Stockfish is a separate free program, not part of this app. It is published
under the GNU General Public License v3, and the full licence text and complete
source code are included alongside it in that folder, which is what that licence
requires. It is the strongest chess engine in the world and it costs nothing:

    https://stockfishchess.org/

If evaluations ever stop working, check that the "stockfish" folder is still
sitting next to ChessHindsight.exe. You can also point at the binary by hand in
Settings.


REQUIREMENTS
------------

Windows 10 or 11, 64-bit.

The bundled Stockfish is the AVX2 build, which needs a CPU from roughly 2015 or
later. That covers almost everything, but on an older machine the engine will
refuse to start while the rest of the app works fine. If that happens, download
the "SSE4.1 / POPCNT" build from stockfishchess.org and drop it into the
"stockfish" folder in place of the existing one.

The UI renders through Microsoft Edge WebView2, which is already installed on
Windows 11 and on up-to-date Windows 10. In the unlikely event the window opens
blank or never appears, install the "Evergreen Standalone Installer" from:

    https://developer.microsoft.com/microsoft-edge/webview2/


IF SOMETHING GOES WRONG
-----------------------

There is a log at  data\chesshindsight.log  next to the exe. Send that along
with a description of what you were doing and it should be diagnosable.
